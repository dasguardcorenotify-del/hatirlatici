# Generative AI assistance disclosure

The project owner used generative-AI coding assistants extensively during the
development of Hatırlatıcı.

AI assistance affected substantial portions of:

- application source code;
- automated tests and QA tooling;
- project documentation;
- Flatpak packaging and release automation.

A reliable line-by-line percentage is not available. The owner ran the
documented tests, reviewed the resulting behavior, controls the upstream
repository, and accepts responsibility for ongoing maintenance and security
updates.

This disclosure is intentionally conservative and must remain visible to
reviewers. An AI tool or agent will not open or automate the Flathub submission
pull request and will not generate its commit message, PR description, review
comments, or replies. Those submission and review communications are reserved
for the human owner.
